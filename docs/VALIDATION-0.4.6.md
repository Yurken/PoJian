# v0.4.6 作品数量柱状图和每日观点饼图

柱高改为对应时段的去重作品数，不再以风险线索分数控制。纵轴动态取最高数量，渐变色只表达数量。今天和过去24小时按小时，七天按日期；初次显示小时图滚到最近有作品的时段，避免停在凌晨空白时段。

点击柱子在图下方直接展示该时段的观点分组，展开组可查看传递该观点的作品、原句、原始材料和窗口内停留时长。没有提取到观点的作品仍计入数量，归到“暂未识别观点”，不生成虚构观点。

新增每日观点饼图：同观点作品合并，按当天全部去重作品数作为分母（含未知观点）。同一作品跨小时观看在每天的饼图里只计一次。某个作品有多个采样或回看记录时，优先选择已有观点的记录作为代表。今天和过去24小时模式显示今天的饼图，七天模式显示所选日期的饼图，日期清楚标注。饼图指接触占比，不意味着用户认同或接受观点。

当前离线归组依据已有明确概括规则及相同标签；保留否定表达，尚不能识别所有同义观点，每个作品只取一个代表性观点候选。后续语义模型接入前，不能保证每个作品都有准确观点。作品身份仍是现有启发式，未知身份记录可能重复，本次不是作品ID精确采集升级。

自动验证新增：同观点多作品归组、未知观点进入分母、百分比守恒、跨小时作品去重、文案展开尾部过滤、一个作品即进入时段计数。界面回归核对点击后下方显示观点和饼图百分比、跨午夜时长只统计窗口内部分。

PDF/TXT仍保留原分析报告格式，尚未导出本次饼图。风险线索旧算法保留供兼容已有分析代码，但不用于新的数量图。
