# 论文用受控合成数据集 v2

用户已确认用途为论文实验、覆盖七种平台/媒体组合，并允许适当增加总量。本包采用 **8,400 个合成作品标识**：七组合各 1,200 个、六领域各 1,400 个。与 App 演示 v1 分开，不能混用二者的分母或结果。

全部内容由 AI 编写的确定性生成器构造，没有采集真实参与者、平台图片或音频，也没有请求云端模型。它支持受控的下游规则实验、时间与身份一致性实验，不能据此报告真实用户心理影响、自然语料泛化或端到端多模态理解性能。研究数据库 `research-synthetic-v2.sqlite` 使用独立研究 schema，不能覆盖 App 的 `zhiheng.db`。现已另建带外键与索引的 [项目实验数据库](PROJECT_RESEARCH_DATABASE.md)，App 可读取全部作品及按虚拟用户隔离的历史。

## 数据规模与配额

| 数据 | 总量 | 训练 | 验证 | 测试 |
| --- | ---: | ---: | ---: | ---: |
| 合成作品 | 8,400 | 5,880 | 1,260 | 1,260 |
| 部分观察版本 | 25,200 | 17,640 | 3,780 | 3,780 |
| 当前材料—历史配对 | 16,800 | 11,760 | 2,520 | 2,520 |
| 情绪—原因—角色片段 | 11,200 | 7,840 | 1,680 | 1,680 |

七种组合为小红书图文、小红书短视频、抖音短视频、快手短视频、微博、微信视频号、微信公众号。每种组合训练/验证/测试分别为 840/180/180 个作品。六领域为就业与教育、性别与家庭、科技与产品、经济与消费、健康与生活、公共议题；每领域划分为 980/210/210。

历史配对覆盖八类场景：同观点新论据、同义改写重复、条件扩展、解释变化、行动变化、引用后反驳、同源转载、证据不足。训练每类 1,470 组，验证和测试每类 315 组。场景名仅用于分层，五维标签分别记录事实、论据、条件、解释、行动的 `new/repeated/unknown`；同源关系和联合覆盖另外保存，不能把八种场景当成互斥的五维标签。

另有 200 个**虚拟用户配置**、14 天共 2,800 个安排的用户日、33,360 次接触和 2,780 条模拟自报。20 个用户日显式标为缺失，其他日期只包含 12 段可见观察，并保存所有未观察区间，不是全天连续采集。日单元从模拟北京时间 09:00 到次日 09:00。

页面回归包含两平台各 120 条、共 240 条合成轨迹，由 12 种操作模式在两平台各展开 10 次，每条 4 次采样；另有 120 个截图授权、窗口、迟到、存储及删除安全规格。它们不是人工手机操作录制，也不是相互独立的 240 个真实页面样本。

## 生成、隔离与时序

1. 固定种子 `20261012`。先分配 72 个语义家族及 840 个源案例，再展开作品。每个源案例包含两份历史锚点与八种当前材料，作者、作品身份、同源关系和定义的近重复家族不跨划分。测试为 126 个源案例、12 个留出的语义家族。
2. **句式仍共享四种生成框架**。家族隔离不等于自然语言模板完全独立；规范化正文检查去除数字和合成标识后没有完全相同文本跨划分，但这不是穷尽的近重复语义审查。不得把 8,400 行宣称为 8,400 个独立自然故事。统计不确定性应按源案例或家族重采样，不能按扩展行当作独立观测。
3. 每作品三个版本依次保留观点前缀、论证、情绪与评论上下文；每版本有 `observed_at` 与 `available_at`。历史必须满足观察时间和可用时间均严格小于当前查询时间，且属于同一划分与源案例。后续评论不会出现在早期版本。历史材料不能用当前作品本身冒充。
4. 模态字段包含可见文本及带作品关联的 `ocr_proxy/asr_proxy`。这些是编写的转写代理，没有实际像素、声波或 OCR/ASR 误差。实际图像编码器、音频识别器和跨模态质量在本包中**未评价**。
5. 输入与标签分目录保存；目标增量标签不进入分析器。实际运行给定结构化观点输入，评测的是现有 `CognitiveAnalyzer` 的历史判断，不能把此分数称为观点抽取或语言模型准确率。

## 情绪归属与长期序列

情绪片段区分正文作者自述、被引用者和评论者，保存表达、原因、对象、处境、归属、表达方式及连续原文跨度。包含焦虑、平静、安心，以及“并不焦虑”的否定；从不根据停留时长填写观看者情绪。跨度为 Unicode 码点左闭右开索引，当前文本没有辅助平面字符。

认知评价保留五个维度的适用性掩码。未提及的控制可能和应对资源不填负例，而是空值。已设定的等级 3 是生成方案的模拟强度，尚未经人类标注者校准，不可用于声称有序标注一致性或临床有效性。全部标签状态为 `AI_authored_unreviewed`，没有双人复核、第三人裁决或 Cohen's κ。

虚拟用户分成四个各 50 人的受控组：“接触集中度高/低 × 内容焦虑表达高/低”。高、低集中组分别安排每日 10/12、3/12 次接触主要语义家族；高、低内容焦虑组分别安排 9/12、2/12 次接触肯定或转述焦虑的材料。情绪比例与集中条件独立旋转分配。模拟自报独立保存，不能用内容标签替代个人反馈。

两套长期协议分别保留字段，不能相加为独立样本：

| 协议 | 训练 | 验证 | 测试 |
| --- | ---: | ---: | ---: |
| 用户隔离 | 140 配置 / 1,960 安排日 | 30 / 420 | 30 / 420 |
| 时间隔离 | 所有配置前 8 天 / 1,600 安排日 | 随后 3 天 / 600 | 最后 3 天 / 600 |

两种训练许可分别存在反馈文件中：测试用户反馈不能进入用户隔离训练；时间隔离只允许前八天且在测试开始前已可用的反馈。反馈时间晚于当天最后可见片段，严格早于允许适配的截止点。当前没有实际训练或个体适配模型运行。

## 实际执行结果（2026-10-12）

使用当前开发分支的实际 `CognitiveAnalyzer`，在冻结的测试输入与预设标签上执行；没有为了提高分数改分析器或按预测改标签。基准提交为 `a7ae7058c1594e9d8ee73288c2d654e28cf8a618`，工作区包含此前作品身份修复，精确版本以结果中的源码 SHA-256 为准。

- **目标 2,520 项，正确 2,370 项，准确率 94.05%，支持类别 macro-F1 0.9583。** 从训练标签确定的多数类基线为 37.50%。排除 4,566 行仅用于历史上下文的输入，防止其容易预测的结果抬高分数。
- 八类各 315 项；“同义改写/联合覆盖”正确 165 项（52.38%），另外 150 项被预测为 `NEW`，预设为 `REPEATED`。其余七类在此受控样本中各 315 项预测一致。保留全部错误 ID、完整混淆矩阵及逐条预测。
- 五维标签存在，但现有分析器只有标量增量类别，本次**不报告五维模型分数**。也不报告情绪抽取、持有者识别、人工标注一致性、多模态识别或心理效果分数。
- 实际 `CaptureSessionTracker` 回放 240 条轨迹、960 个采样：边界错误 0/960、身份成对关系错误 0/1,440、作品数错误轨迹 0/240、观看次数错误轨迹 0/240、对预设可见区间的时长 MAE 0 ms。已提供可靠页面提示和准确时钟，所以不能推广为真实页面身份识别或手机计时误差。
- 120 个安全规格携带请求/回调上下文、独立本地保存与上传授权、窗口、存储与删除状态；没有设备执行结果。未启动模拟器或真实手机。
- 独立数据审计通过：数量/配额、定义的隔离组、规范化相同文本、历史时点、版本内容、原文跨度、缺失区间、双协议反馈许可与 SQLite 表计数/完整性。10 项新增 Python 测试验证未来信息拒绝、跨组拒绝、目标分母、空分母与拒识处理。

论文可引用的指标范围建议写作：“在 AI 编写且未经人工复核的受控合成测试集中，给定结构化观点字段，现有历史判断模块在 2,520 个目标配对上的预设标签一致率为 94.05%，macro-F1 为 0.9583；该结果不衡量端到端多模态理解或自然语料泛化。”

原 LaTeX 中的志愿者实验、人工一致性和其他模型分数不能由本合成包提供证据。本次没有覆盖原论文或替它生成未执行的实测数值；应与原实验的独立来源分别引用。

## 文件与复现

默认数据目录：`app/build/research-synthetic-v2/`。结果目录：`app/build/reports/research-v2/`。

| 目录/文件 | 内容 |
| --- | --- |
| `inputs/works.jsonl`、`versions.jsonl` | 作品、作者/源分组、平台组合及可见版本 |
| `inputs/increments.jsonl` | 当前版本、过去历史及查询截止点 |
| `labels/arguments.jsonl`、`increment_labels.jsonl` | 结构化标注、五维预设、关系及旧分类器的目标标签 |
| `labels/emotions.jsonl` | 11,200 条情绪—原因—角色标注 |
| `inputs/user_days.jsonl`、`contacts.jsonl` | 安排日、缺失、可见区间与接触作品 |
| `labels/profiles.jsonl`、`feedback.jsonl` | 实验条件、虚拟用户划分与模拟自报；不自动输入模型 |
| `inputs/traces.jsonl`、`labels/trace_labels.jsonl` | 可回放页面提示与预设作品/观看边界 |
| `inputs/safety.jsonl`、`labels/safety_labels.jsonl` | 尚未执行的安全规格 |
| `research-synthetic-v2.sqlite` | 独立研究数据库；每表为稳定 ID 与 JSON payload，可用 SQLite JSON 查询 |
| `manifest.json` | 固定种子、规模、生成器与数据 SHA-256、来源和限制 |
| `legacy-test/` | 现有下游评测器使用的冻结 TSV 输入和标签 |
| 结果中的 `target-summary.json`、`RESULTS.md` | 只包含目标项分母的正式结果 |
| 结果中的 `history/predictions.tsv` | 所有预测；`.history*` 行仅为上下文，`.target` 行才是本次评分目标 |

在仓库根目录使用 Python 3.10+：

```powershell
python scripts/build_research_dataset.py
python scripts/audit_research_dataset.py app/build/research-synthetic-v2 --output app/build/reports/research-v2/data-audit.json
python -m unittest discover -s scripts/tests -p 'test_research*.py' -v
```

脚本只允许重写自己持有的输出目录，不能将真实 App 数据库作为目标。主机审计无需 Android、手机或模型服务。

用项目正常 JDK/Gradle 环境运行实际算法：

```powershell
.\gradlew.bat :app:evaluateHistoryQuality :app:evaluateSyntheticTraces --offline `
  '-Pquality.dataset=绝对路径/app/build/research-synthetic-v2/legacy-test' `
  '-Pquality.output=绝对路径/app/build/reports/research-v2/history' `
  '-Presearch.dataset=绝对路径/app/build/research-synthetic-v2' `
  '-Presearch.output=绝对路径/app/build/reports/research-v2'
python scripts/summarize_research_evaluation.py app/build/research-synthetic-v2 app/build/reports/research-v2
```

本机固定签名缺失，本次**仅非 APK 的离线评测任务**使用 `-x :app:verifySigningIdentity` 执行，未生成或替换签名。评测代码在 `evaluation/kotlin/`，预测与标签文件独立；输出必须位于标注目录之外。未推送、未更改版本、applicationId 或分发配置。

`history/report.md` 的通用整体指标包含历史上下文行，本研究应引用 `RESULTS.md` 与 `target-summary.json`。进一步开发模型时冻结本版结果；若用这些错误调试算法，本集应转为回归集，再构建新的留出集，不能继续称其为未见测试。
