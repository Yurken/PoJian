# 实时监测：架构与部署边界

本文保留监测链路的架构与范围说明。后续持久任务、可见区间及历史比较变化分别见更新日志的 [0.4.9](CHANGELOG.md#v0-4-9)、[0.4.10](CHANGELOG.md#v0-4-10) 和 [0.4.11](CHANGELOG.md#v0-4-11)；2026-10-08 的初始检查见[监测链路历史条目](CHANGELOG.md#monitoring-2026-10-08)。队列、保存位置和 Android 验证状态以对应版本记录及[当前实现对照](IMPLEMENTATION.md)为准。

## 运行链路

`BrowseAccessibilityService` 在已授权应用范围内挂载 `MonitorAccessibilityBridge`。桥接器提供辅助功能悬浮层、可见屏幕上下文和画面采样；App 的 `MonitorRuntime` 观察 Room 新增文字与稳定转写，通过有界队列调用 `/monitor`。返回声明进入独立事实核查列表，结构化观点进入 `MonitorPolicy` 的保守重复观察，提醒再经过上下文、冷却和每日上限判断。

App 一级导航为概览、发现、设置。录音、模型下载、音频导入位于设置中的采集工具，旧手动音频回顾仍可使用。悬浮球默认关闭、显示时可拖动；自动提示只展示短文本，操作按钮需要用户主动展开。暂停全部监测会关闭采集并停止播放音频任务。

本轮使用 `TYPE_ACCESSIBILITY_OVERLAY`，不是新建长期全屏透明浮窗。截图声明 `canTakeScreenshot`；Android 14+ 调用 `takeScreenshotOfWindow`，Android 11–13 调用 `takeScreenshot` 后裁取目标窗口并暂时隐藏自身浮层；Android 10 明确不支持该截图链路。来源拒绝内录或安全窗口拒绝截图时不绕过限制。

官方 API 依据：[AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)、[AudioPlaybackCapture](https://developer.android.com/media/platform/av-capture)。截图权限、辅助功能与系统原有录音提示保持可见和可撤销；配置自己的 API 不代表没有向提供方传输材料。

## 范围、身份与成本

当前实现的输入类型为可见文字、口播转写和画面采样。每条请求有来源应用、采样 ID、输入类型、采集时刻和上下文令牌；视觉模型提取文字在记录中标记 `visual_model`，不制造测量停留时长。读取到的外部网页仅用于取证，不进入浏览接触历史。

画面采样先通过随 APK 打包的中文 OCR 识别图片与字幕文字（`com.google.mlkit:text-recognition-chinese:16.0.1`），无需首次下载识别模型。OCR 在后台处理最长边 1600 像素的目标窗口副本；同一时间至多一个识别任务，等待上限 15 秒。取消或超时后，原生任务持有的副本只在原生完成后回收，期间拒绝新识别；OCR 失败仍可继续既有画面分析。已完成的同屏像素去重会同时省去 OCR 与上传。检测到可见输入框或密码框时跳过画面采样。

识别结果仅去除与辅助功能文字完全相同的整行，不按相似度删除否定、数字或条件。新增文字先以 `screen_ocr` 保存，记录页及原文详情显示识别来源与关联事件编号；不保存截图。附近六秒内有同应用且匹配当前文字的浏览记录时，以 `parentEventId` 绑定；无法可靠匹配时保持未关联。多个 OCR 片段不能重复计为多次接触；未关联片段不贡献重复风险的独立接触数量。Room 6→7 保留旧数据并增加自关联外键，删除父记录同时删除关联 OCR 与派生结果。

云端画面分析失败时，已保存 OCR 文字转入现有加密持久任务队列，沿用容量、授权、重试次数、时限和总请求额度；达到额度、撤权或删除时不会绕过限制。队列满时保留原文并反馈未核查。当前 OCR 复用已有“画面分析”开关，仍需开启云端分析并满足画面采样条件；不是独立常驻的离线采集模式，未增加设置入口。

识别输入与输出由 ML Kit 在设备上处理；SDK 会向 Google 发送运行与使用指标，隐私说明已补充。之后若启用既有云端分析，文字与采样画面仍按现有授权发送配置的服务端。依据：[Android 文字识别集成](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)、[ML Kit 数据与隐私条款](https://developers.google.com/ml-kit/terms)。

前台接触标识和音频会话用于保守归并：一段长录音的多个切片不能单独组成八次接触，云端画面/文字在同一次前台接触内也不重复计数为独立接触。现有本地回顾仍基于保留快照和规则，不具备完整帖子身份识别。此处不能宣称已经实现小红书多图笔记与短视频条目的可靠跨页归并。

默认画面基础采样间隔 30 秒，可在 15–120 秒间调整。页面稳定至少 800 毫秒后才自动采样；同一上下文中的已完成画面连续不变时，间隔按基础值的 2 倍、4 倍退避，最长 120 秒。切屏、滚动、可读文字或授权变化重置退避，同时保留全局基础间隔限制；手动核查跳过稳定等待、退避和像素去重，但仍受容量与额度限制。调度使用单调时钟，记录仍使用实际采集时间。

截图的硬件位图复制、目标窗口裁剪缩放、像素指纹、JPEG 与 Base64 编码在后台执行。裁剪直接绘制到最长边 960 像素的工作位图，避免额外创建原尺寸裁剪副本。只在同一上下文、授权版本内，对五分钟内成功完成分析的缩放画面比较精确 SHA-256 像素指纹；相同画面省去重复 JPEG 编码与提交，不使用感知相似度忽略局部变化。失败或未接收的画面不记为已完成，允许后续重新采样。JPEG 超过 180 KiB 时，在质量 45/35、最长边 960/768/576 内有限重试，仍超限则保留原有错误反馈。所有中间位图和硬件缓冲在完成或取消时释放。

文字最多 6000 字，近邻稳定口播保留最多四段、约 30 秒上下文。文字/音频持久任务容量 6（含运行与重试），画面只允许一个待处理或运行中的任务。自动截图在视觉任务未完成或持久队列满时暂缓，避免先编码再丢弃；两类任务均就绪时轮流处理。过时或队列未接收的内容不等于已经核查。

完全相同输入仅在当前进程中短期缓存五分钟，响应通过校验后才进入缓存，缓存区分是否实际请求事实核查；手动核查不能复用“只分析、未取证”的结果。当前不是语义改写缓存、完整重复视频去重或逐帧场景识别。画面额度、共享云端请求额度、服务端每日请求额度分别限制开销，不能当作精确费用账单。

## 提醒与证据约束

默认同一议题或声明 30 分钟内不重复提醒，每天最多六次，自动提示三秒，始终静音且不振动。用户可调整这些参数、夜间静默和专题研究模式。只有有外部证据的矛盾结果或满足保守门槛的持续重复线索可主动提示；未知、未核查与价值判断不会弹出“虚假”告警。

屏幕切换、滚动事件会撤销上下文绑定；结果必须仍属于当前令牌且不超过两分钟，才可能主动提醒。切换之后完成的结果可在发现页查看，不能代指下一屏。纯视觉变化未触发可观测事件时，要到下次采样才能发现，静态退避可能使等待达到 120 秒；工作分辨率以下的细节或两次稀疏采样之间的变化仍可能漏记，需要真机评测，不承诺完整字幕或切屏覆盖。

服务端先从输入抽取最多三条声明，最多对一条事实声明调用 Tavily 正文检索和证据对齐。引用只能指向实际返回的 HTTPS 来源，逐字引文必须出现在取回正文；只有摘要时保留证据不足。语义正确性和来源可靠性仍需复核，字符串校验不是事实真实性证明。客户端再次检查声明引文、来源引用、请求 ID 与不确定归属。

删除或更正材料后清除旧派生结果、比较材料和临时缓存，作废旧请求。当前采用保守的整体失效而非细粒度持久化依赖图。实时发现和提醒比较缓存保留至多 80 项发现、600 项比较材料，存于本地私有 SharedPreferences，未额外加密，退出应用不代表删除。绑定原记录的已接收结构结果及持久任务另在 Room 保存，任务副本加密和恢复边界见[当前实现对照](IMPLEMENTATION.md)。截图与原声不在本模块落盘。

## 待验证能力

需要验证真实图文/短视频的覆盖、OCR 准确率、声画与声明归属、画面内否定与图表条件、每小时误提醒、端到端延迟、API 实际用量和电量。完整多页内容归并、训练后的观点语义模型、跨来源独立性、时序图、精确声画同步、连续视频推理、深度伪造鉴别和安全硬件证明均不能由本轮工程回归代替。稀疏截图上的 OCR 不代表完整视频字幕采集。
