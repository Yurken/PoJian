# Swiss Minimalist UI implementation plan

> **For agentic workers:** Use subagent-driven-development with separate file ownership; root integrates and verifies.

**Goal:** Rebuild PoJian's presentation as five Swiss Minimalist tabs using the supplied HTML layout and actual retained data.

**Architecture:** Existing Room, capture, audio and analysis contracts remain unchanged. Pure display adapters derive charts and summaries; Compose state owns navigation and filters. Unsupported research/security metrics remain explicitly unverified.

**Tech Stack:** Kotlin, Jetpack Compose, existing Material 3, Android View overlay, JVM and Compose test compilation.

**Spec:** User's 2026-10-16 request and attached HTML prototype.

## Constraints

- White #F8FAFC page, #FFFFFF 16dp bordered cards, #09090B primary, exact prototype HSL mapping.
- No new explanatory subtitles; only required controls, data and truthful states.
- No fake source independence, TEE, encryption, probability or performance metrics.
- No emulator; do not alter applicationId, signing, database or inference contracts. A user-authorized push increments the patch version and versionCode under AGENTS.md.
- Current checkout is the writable workspace; use local feature branch. The follow-up request authorizes committing and pushing this implementation.

## Review focus

- Unknown/stale analysis must not become 0% or a security success.
- Large text and narrow widths must retain reachable controls.
- Heatmap boundaries and source-duration denominators must stay truthful.
- Keyword/topic navigation and dismiss/back retain expected filters.
- Export/report switches must not mix time windows or stale snapshots.

## Delivered behavior and data boundaries

- Five pages share the white bordered theme, ink controls, tabular numbers and brand icon. Header and overlay use the same prototype HSL calculation, including its threshold behavior.
- Hotwords open filtered history; topics open their viewpoint page. History also retains free-text search, original content, evidence matches, associated transcripts and deletion controls. Tab state is retained across navigation.
- Reports retain the browsing-purpose editor, use actual hourly/daily/monthly analysis, include real queued/failed analysis counts, and export PDF/structured JSON. Export snapshots survive Activity recreation and are invalidated when retained content, purpose, analysis state or report window changes.
- The existing analyzer supplies seven-day viewpoint concentration, not a calibrated cocoon probability. Its real scope is shown on the ring and overlay; unknown values stay unknown. Independently verified sources and facts are not inferred from repeated quotations. Hotword frequency does not manufacture a diversity classification.
- TEE, operator plaintext-access guarantees, payment-page detection, risk-versus-exaggeration classification, continuous anxiety duration, OCR latency and ASR RTF have no verified backing data in this project. Their requested positions show unavailable/unverified states instead of prototype numbers or security successes.
- Storage retains the existing capacity-based policy; reminders retain the existing fixed 30-minute observation window. No nonfunctional 7/30/90-day or 15/30/60-minute selectors were introduced. The thumbnail action explicitly clears and disables thumbnails using the current setting.
- Overlay actions call the existing current-content check and information-gap entry. The manual action is labeled “核查当前内容” because that existing operation does not guarantee an explicit save.
