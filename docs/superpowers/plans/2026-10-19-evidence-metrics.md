# 新增事实与独立来源实施计划

> 执行方式：使用 superpowers:executing-plans 在当前工作区逐项实现；用户已要求补齐两个指标。保留已有 PDF 未提交文件，本轮提交只包含本任务。

**目标：** 替换两个固定“未核实”，让数值由当前时段、主题和保留原文计算；证据不足继续保留未知。

**设计：** 新增事实只统计相对于可比较历史被识别为新增的事实类片段，首次出现及条件变化不冒充已完成历史比较。重复片段去重，已比较零新增与无法比较分开。来源沿现有模型响应增加可选的原文溯源结构，保存原始信息产生者、材料、采集依据、上游材料及完整性；仅有原始采集依据的来源成为根，转载/共享材料合并。结果是基于保留原文的来源关系识别，不是外部真实性认证。

**技术：** Kotlin/Compose、现有 JSON 语义存储、Python 网关；不新增服务请求或依赖，不迁移 Room。

## 约束与审查重点

- 不新增模块介绍、教学文案或装饰标签；沿用“新增事实”“独立来源”，仅增加必要数值/状态及原文数据。
- 来源、材料名称不能仅因不同就被视为独立；同一产生者、同一原始材料、明确共同上游合并。
- 引文必须连续存在于对应 evidence，来源名称必须存在于该引文；缺失、否定原始采集、空字段、伪造引用不得进入确认计数。
- 旧记录无新字段兼容为未知；文本修订、删除、最新空结果、附属素材归属及主题/时段筛选不得留下过期计数。
- 部分可判断时保留已知数及未知状态，不把未知当零；计数不得包含未浏览的外部检索材料。
- 只本地提交，不推送、不调整版本或签名。
