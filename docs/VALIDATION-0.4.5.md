# v0.4.5 观点时间柱状图

概览新增白色卡片柱状图，今日和过去24小时按小时，最近7天按日期。小时图可横向滑动。柱子高度对应0–100的本地风险线索分数，固定纵轴内从绿色、黄色到红色渐变。点击每个柱直接打开该时间窗口内的作品、简短观点候选、原文出处和窗口内估计停留时间。灰色代表无法评分，空时段不伪造观点。

观点标签按实际句子构造；“就业/求职/招聘/裁员/找工作”结合焦虑或困难线索可概括为“就业焦虑”；女性与独立、自主线索可概括为“女性独立”。否定表达保留原句，其余候选显示原文的简短摘句，不将经济或科技等大主题冒充观点。优先使用已生成报告的观点原句，否则从保留文字中选取含观点谓词的候选。当前每个作品显示一个候选，不是完整语义理解。

分数仅反映已采集内容中的线索，至少3个不同作品有候选后才计算：相同标签额外出现次数/候选作品数×60＋含明显情绪表达的作品数/候选作品数×40。数字越高表示这两个线索越集中，不是用户认知已受影响程度的科学测量。没有模型或实证校准，不能用于诊断。数量和停留时长不直接提高分数；重复观看同一已识别作品不作为多个评分样本。缺少作品身份和文字误识别仍影响结果，未识别到观点的内容不进入分母。评论与正文尚未完全分离，需回查原文。

保留原有作品总数、观看次数和各平台时长。PDF/TXT沿用原报告内容，尚未嵌入新柱状图与风险线索分数。旧主题分析字段保留为内容分类，新的观点时间卡片不使用这些分类作为观点标签。

自动回归覆盖：具体观点与否定表达、浏览数量不直接评分、重复观看去重、计算依据可复核、整点时间归属、日范围过滤和音频排除；更新跨午夜详情UI测试，核对只显示窗口内时长。

验证结果：APK和测试APK构建成功，105项JVM测试通过，2项Android界面测试通过，Lint无错误、7项既有警告。已检查七日柱状图与点击详情截图（测试数据）。OPPO真机新版尚待验收。
