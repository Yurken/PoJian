## 解释原则

主题集中、观点集中、依据重复和事实真假是不同问题。价值观不是风险黑名单；支持与反对均按相同证据标准分析。接触不等于认同，观察结果不证明平台推荐的因果机制。系统检索到的外部证据不会混入用户接触历史，模型提取的画面文字明确标为 `visual_model`。

目前以有限可见采样和保守接触归并控制误提醒，不能把一次屏幕快照称为完整笔记或完整视频。云端只返回最多三条候选，每次最多检索一条事实；其余明确为未核查。引用存在只代表可以追溯到取回的材料，不证明模型的语义判断正确。

0.4.8 的验证范围与结果见 [统一观点分析链验证](VALIDATION-0.4.8.md)。下列 2026-10-08 记录描述当时环境，不能作为最新版本的验证结果。

本轮实际运行了 35 项独立 JVM 提醒策略与重复规则回归，以及 55 项 Python 网关输入、证据、预算和 HTTP 契约测试，均通过。外部模型与检索使用确定性假上游，未调用用户付费 API。新增代码做了 Kotlin 语法检查；该检查不是 Android 编译。

当时执行环境缺少 Android SDK，不能据此声称 APK 构建、Compose/Room 仪器测试或真机目标平台已通过。代码、权限分支、费用默认值和上述限制见 [实时监测说明](REALTIME_MONITORING.md)。已有历史构建记录不自动覆盖本轮变更。
