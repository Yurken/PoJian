## 解释原则

1. 内容可见、估计停留、实际阅读、理解和认同分别代表不同层次。
2. 一致结论可以由不同事实支持，负面消息可以有价值；无依据也不自动等于低增量。
3. 新片段只说明在当前保留历史中出现了不同文字，不证明真实性、独立性或知识增长。
4. 本地数据可能缺少快速划过、画面、未转写音频和不暴露节点的内容；空白时段不证明用户未浏览。音频转写不增加估计观看时长。
5. 各项研究任务需要独立实验，构建和工程回归通过不等于学术准确率或用户效果已验证。

## 后续实现依赖

音频路线已经接入；参赛评测仍需真实目标设备、合法音频样本与独立标注。原声保存/回听、独立 VAD、自动跨视频归并、画面理解、双路编码和时序图尚未实现。文字服务已完成假上游契约测试，未以付费 API 成绩代替实际评测。可信计算需真实硬件、证明策略和密钥服务。
