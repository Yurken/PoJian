本文件区分第一章提出的研究目标与当前可运行原型。版本：0.3.0。

## 解释原则

1. 内容可见、估计停留、实际阅读、理解和认同分别代表不同层次。
2. 一致结论可以由不同事实支持，负面消息可以有价值；无依据也不自动等于低增量。
3. 新片段只说明在当前保留历史中出现了不同文字，不证明真实性、独立性或知识增长。
4. 本地数据可能缺少快速划过、画面、音频和不暴露节点的内容；空白时段不证明用户未浏览。
5. 各项研究任务需要独立实验，构建和工程回归通过不等于学术准确率或用户效果已验证。

## 后续实现依赖

多模态与语义模型需明确模型、推理位置和标注样本；时序图研究需独立的论证关系标注与时间切分；可信计算需真实硬件、证明策略和密钥服务。接入这些能力时应继续保留原文核查、未知状态、采集范围和删除一致性。
