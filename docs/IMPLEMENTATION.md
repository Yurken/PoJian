## 解释原则

主题集中、观点集中、依据重复和事实真假是不同问题。价值观不是风险黑名单；支持与反对均按相同证据标准分析。接触不等于认同，观察结果不证明平台推荐的因果机制。系统检索到的外部证据不会混入用户接触历史，云端模型提取的画面文字标为 `visual_model`，端侧文字识别标为 `screen_ocr`。OCR 片段通过 `parentEventId` 关联同次浏览；删除原浏览记录会级联删除关联片段。片段不增加观看次数或时长，也不能单独凑足重复风险的接触门槛。

目前以有限可见采样和保守接触归并控制误提醒，不能把一次屏幕快照称为完整笔记或完整视频。云端只返回最多三条候选，每次最多检索一条事实；其余明确为未核查。引用存在只代表可以追溯到取回的材料，不证明模型的语义判断正确。
