# 破茧个人认知体检需求

更新：2026-10-16。依据用户提供的《第一章2.0.md》，实现对照基线为 `4e997cf`／`v0.5.41`。本文整理产品需求、代码差距与验收条件；文章中“提出”“实现”等表述不作为算法或安全能力已经完成的证明。

产品主线为：从用户实际接触的信息中整理观点与论据，识别长期重复和情绪表达集中，帮助用户回顾已有信息、自主补充资料，并以可验证机密计算保护敏感数据。界面沿用已确定的“信息视野”名称。

## 分析与统计边界

1. 只分析用户授权范围内实际采集到的内容；可见采样不等于已读全文、完整视频或用户注意力。
2. 主题集中、观点集中、论据重复、情绪表达与事实真假分别记录。接触不等于认同，负面表达不等于有害内容，内容情绪不等于用户心理状态。
3. 区分作品数、观看次数、观点记录数和独立论据数。同一作品重复观看、多次截图、语音切片与转载，不能虚增独立证据。
4. 信息视野中的集中度或重复比例不是“陷入信息茧房的概率”。无数据时保留明亮开放的视觉，但数值未知仍显示“—”。
5. 数据不足、归属不明、历史检索截断或来源关系未确认时保留未知，不把缺失当成低风险、零情绪或零新增信息。新增信息只相对于已知历史，不代表全网首发或事实已经证实。
6. 外部检索材料与已浏览历史分开保存。检索到材料不代表用户已经阅读，也不能直接提高已接触观点的多样性。
7. 不按立场设黑名单、不强制推荐相反观点、不推断心理疾病；教育场景以自愿参与和个人查看为原则，不默认向教师或组织开放浏览历史。

以上边界对应原文 §1.1.2、§1.2.1–1.2.3、§1.4.1、§1.5.2–1.5.3，并延续已有产品约束。

## 功能需求

### R1 个人信息体检

来源：§1.4.1（1）、§1.5.1。

- 按 24 小时展示浏览时间分布及各时段主要主题，可追溯对应作品、接触记录和原始材料。
- 分开展示观点分布、重复论据与新增事实或解释；对同一主题持续阅读但不断获得新依据的情况，保留新增信息。
- 时间按实际可见区间统计，跨小时拆分，暂停空档不计入。主题和观点的分母、未知覆盖及重复作品归并规则需一致。
- 验收重点：作品详情、时段图与报告可核对；截图和语音片段不会制造额外观看或时长。

### R2 信息视野与长期重复提醒

来源：§1.1.3、§1.2.1、§1.4.1（2）。

- 在相同议题、对象、评价维度和适用条件下，联合考察观点集中、论据重复、信息新增和持续时间。
- 区分同观点新论据、同观点同论据、条件变化及无法判断；不同账号改写同一事件不能被直接当作独立证据。
- 提醒须可回查触发主题、时间范围、相关作品和重复论据；正常专题学习、短时集中阅读与长期缺少新依据应分别处理。
- 保留现有关闭、冷却、限频、静默与专题研究控制；数值阈值需通过标注评测确定，不能因文章使用“风险”一词就新增概率分。
- 验收重点：同主题但持续出现新证据的样例不因主题集中而触发；长期同论据重复的样例能提供具体历史依据。

### R3 内容情绪分析与提醒

来源：§1.2.2、§1.3.3、§1.4.1（3）、§1.4.2（4）。

- 记录内容表达的情绪、强度、关联事件或诱因、原文依据及不确定性，结合文字、画面与口播语境。
- 区分事实性风险提醒、正常社会批评、引用他人表达与强烈绝对化判断；不能只靠负面词数量分类。
- 按主题和时间展示不同情绪内容的比例与长期变化，持续集中时按用户设置提醒，并可回查内容。
- 情绪占比明确使用作品数、接触次数或时长中的哪种分母；未分析内容不计为中性。类别和多情绪计数规则在实现前确定。
- 验收重点：系统描述“接触内容中的焦虑表达”，不据此判断用户焦虑、心理健康状态或认知受损。

### R4 信息盲区提示与主动补全

来源：§1.4.1（4）、§1.5.4。

- 根据个人已有记录指出某议题目前涉及的观点、论据与条件局限，不宣称掌握全部观点或完整现实。
- 用户可选择补充尚未充分涉及的事实和解释，查看原始来源及不同材料之间的引用或转载关系。
- 按“提供新增依据”整理补充材料，不机械推荐相反立场，不将不同网站重复转载当作多份独立证据。
- **拟定边界**：历史覆盖提示复用已有分析；用户主动选择补全时才检索外部资料，不持续后台搜索。此边界协调 §1.4.1 的“检索尚未充分涉及的信息”与 §1.5.4 的“不依赖持续的外部网络检索”，仍需在实现前定稿。
- 验收重点：仅生成补全结果不改变浏览统计；离线或未配置检索时，已有历史整理仍可使用，不能生成虚构来源。

### R5 主题观点整理

来源：§1.1.3、§1.3.2、§1.4.1（5）、§1.4.2（3）。

- 将跨时段、跨作品的同主题内容汇总，归纳相同或相近观点，并保留不同条件下的分歧。
- 每种观点关联支持该观点的已浏览作品、主要论据和原始来源；区分作者主张、转述与反驳。
- 同时呈现论据的重复与新增关系。支持作品数量不等于独立证据数量，也不表示观点可靠性或用户认同程度。
- 支持当天回顾及跨期比较，复用已有分析结果；同一作品多次观看可保留接触次数，但不能重复增加支持作品数。
- 验收重点：用户能够从主题总结回到实际采集到的材料；条件不同的判断不会为了合并而丢失否定、时间或地区限制。

### R6 隐私保护与自主控制

来源：§1.1.3、§1.2.3、§1.3.4、§1.4.1（6）、§1.5.3。

- 保留应用范围选择、采集与云端分析开关、暂停、删除和撤权后的任务失效；教育用途不新增默认共享权限。
- 客户端在提交敏感信息前验证可信执行环境及预期程序身份，验证失败不释放数据。
- 会话密钥在受保护环境内生成和保管，公钥与远程证明绑定；敏感数据仅在通过验证的受保护环境中解密和分析，普通转发服务、存储及运维日志不得获得明文或解密密钥。
- 历史记录和分析状态以加密形式管理，通过状态检查点验证完整性和安全更新；报告经加密通道返回。
- 多模态推理、历史检索和外部服务调用必须纳入保护边界评估。仅在入口部署 TEE，却向普通模型 API 转交明文，不能满足该隐私目标。
- 验收重点：真实硬件证明、程序身份、公钥绑定、密钥隔离、历史篡改与回滚处理均需验证。模拟证明、HTTPS 和本地队列加密不能替代这些条件；通信元数据与硬件侧信道不作完全消除的承诺。

### R7 小时每日与长期报告

来源：§1.1.3、§1.4.1（3）、§1.5.1、§1.5.3。

- 提供小时报告、每日报告和长期分析报告，汇总主题、观点、论据新增与重复、内容情绪和对应材料。
- 小时回顾、独立小时报告、定时生成是不同交付范围；现有小时聚合不能直接算作独立报告或调度已经完成。
- 报告保留时间范围、覆盖与不确定性，支持查看原始依据和前后对比；删除或修订原文后，使相关结果失效或重新生成。
- 继续复用既有预览和 TXT/PDF 导出。小时边界、长期窗口长度、自动定时生成与通知方式需另行确定。

## 实施阶段

以下为按依赖整理的实施顺序；本轮工作区结果见文末。

1. **先统一数据与统计口径**：作品、接触、观点和论据分开；补齐来源归属、覆盖、未知状态与修订依赖。支撑 R1、R2、R5、R7。
2. **形成可回顾的产品闭环**：完善主题观点总结、论据关系与跨期回顾，补上信息视野提醒的联合条件，明确小时／每日／长期报告边界；复用现有界面及提醒设置。
3. **扩展情绪与补全**：实现情绪和诱因数据链、主题情绪趋势与提醒；在确定检索边界后接入用户主动补全。
4. **并行推进隐私与研究验证**：R6 从架构阶段启动，不排到产品完成后补做；真实机密计算验收是声称“运营方无法读取明文”的前提。五条研究路线分别提交实现和评测证据。

界面改动应在功能范围确定后单独设计。保留当前信息视野视觉、图表样式和已认可文案；需求中的解释用于研发和验收，不自动成为新增界面文字。

## 关键验收场景

| 场景 | 期望结果 | 需求 |
| --- | --- | --- |
| 同一作品多次打开并产生文字、画面和音频片段 | 观看次数与支持作品数分开；片段不新增观看时长或独立证据 | R1、R5 |
| 多个博主改写同一则新闻 | 保留各作品接触，标识已确认的论据重复；来源无法确认时保持未知 | R2、R5 |
| 同一主题连续数日出现不同数据或解释 | 保留新增依据，不仅因主题集中触发信息视野提醒 | R2 |
| 原句被引用、反驳，或字幕与口播相矛盾 | 保留归属和条件；无法可靠抽取时不强行合并观点 | R1、R5 |
| 没有数据、覆盖不足或报告已过期 | 不显示虚构比例或确定风险；初始视觉与真实统计状态分开 | R1、R2、R7 |
| 数据型风险提醒与“所有人都没有出路”分别出现 | 分析内容语境、情绪与诱因，不将负面表达或社会批评一概判为有害 | R3 |
| 一段时期持续出现同主题强烈情绪内容 | 可回查持续区间及内容依据，遵守提醒开关、限频和静默设置 | R3 |
| 生成补充资料但用户尚未阅读 | 资料可查来源，已浏览观点分布与接触统计保持原值 | R4 |
