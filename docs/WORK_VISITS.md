# 作品与观看统计：口径与核对方法

作品、观看与采样的分离始于 [0.4.2](CHANGELOG.md#v0-4-2)。页面连续性、抖音适配及可见区间的后续变化见 [0.4.3](CHANGELOG.md#v0-4-3)、[0.4.4](CHANGELOG.md#v0-4-4) 和 [0.4.9](CHANGELOG.md#v0-4-9)。本文用于解释计数口径和真机核对方法。

## 需求与计数口径

用户在同一篇笔记翻图、滚动时，不应因文字变化而增加作品数。已识别的作品再次打开时，作品数保持不变，观看次数增加；每次观看的可见停留分别累加。作品身份按平台隔离，跨平台转载不自动视为同一个作品，也不据此认定来源独立。

三个时间范围分别为设备本地今天零点到当前、当前时刻向前24小时、六天前零点到当前。跨边界的停留只计算与窗口重叠的部分。时段内作品分别去重，不能把各小时的作品数直接相加作为总作品数。音频转写和视觉模型提取的文字是材料，不计入观看作品数量或制造观看时长。

## 数据设计与实现

- `observed_works` 保存作品身份、平台、作者、标题及识别方式。
- `browse_events` 保留既有记录和引用ID，作为一次连续观看；新增 workKey、identityMethod。
- `browse_samples` 保存一次观看内变化的可见文字，与观看记录建立级联删除关系。连续相同的文字不重复保存；每次观看最多保留最近120个变化片段，全局最多5000个，超限清理最早片段。
- 相同作品内的可见文字按行去重汇总至既有 visibleText（上限16000字），保持原有分析、搜索和事件引用入口可用。采样片段保存各时刻的文字，不把全文汇总当作一次屏幕的完整状态。
- 旧版本通过 Room 迁移链保留历史记录。0.4.3 曾在已有作者和正文线索支持时保守补充启发式身份、整理重复记录；线索不足的身份仍为 unknown，不补算未观察停留。当前数据库版本及迁移验证见[更新日志](CHANGELOG.md)。
- 删除观看记录会删除其采样；不再被记录引用的作品元数据会清理。删除前开始的采样仍受原有 generation 门控，不能复活已删除记录。

## 身份策略与限制

优先使用平台身份（字段预留）；当前采集适配从已知的标题、作者资源字段构造平台内身份。它是启发式，不是平台真实ID：相同作者使用同样标题仍可能混淆，APP改版或混淆资源ID会导致无法识别。

没有稳定标题时，仅对可见作者相同、总图数相同、图片序号向前相邻变化进行连续采样归并，并标记为 session_estimate。标题冲突、作者冲突、重置到封面或真实应用切换时，不靠作者单独强行归并。没有这些线索时保留原有保守文字连续性策略。窗口短暂缺失或被系统界面遮挡后，同一作品在 15 秒内恢复可延续原观看；这一恢复窗口不代表可以补算不可见的空档。

未知作品以该次观看的临时身份计入估计数；再次打开未知作品仍可能重复计数。界面明确显示“作品接触（估计）”及身份未确认数量。抖音评论和展开页面已按已知样本补充连续性适配，真实平台改版、倒序翻图和缺失作者的页面仍需实际节点核对，不承诺完整作品识别。

观看时长根据相邻可见检查间隔估计，不是注视时间、视频媒体长度或已理解时间。首次采样时长为零，仅未暂停且 1～6 秒的相邻可见间隔计入时长，暂停或超过 6 秒的空档不补算。自 0.4.9 起，新记录保存正文/视频页面、评论区和未定位可见区间，暂停空档不桥接，跨小时按交集分配；旧记录仍保留整次估计和未知区域，缺失时长仍为未知。

## 界面与报告

概览显示估计作品数、观看次数、估计停留及各平台统计。三个时间范围共享同一计算函数。过去24小时按实际涉及的自然小时列出，首尾小时仅计算窗口内部分。

浏览记录按APP折叠，组内按时间倒序；序号按本机保留记录的时间正序生成，数据库ID在展开原文后仍可查看。搜索和应用筛选时自动展示匹配项。删除旧记录会使显示序号重新排列，数据库ID不重排。

PDF/TXT采用相同口径的作品及各平台观看统计。观点分析以观看记录和原文引用工作；模型结构结果与规则候选的统一链路及其范围见[当前实现对照](IMPLEMENTATION.md)，计数口径本身不代表语义模型准确率。

## 真机核对

自动回归覆盖：同标题不同正文、多图前进、同作者不同作品、显式标题冲突、返回已识别作品、跨平台隔离、音频/视觉材料排除、24小时与跨午夜时长守恒、旧数据迁移、样本去重与删除后不复活。

OPPO真机步骤：先核对安装 ID 和签名，再覆盖安装同一包身份的版本；0.4.8 起的标准包 `com.zhiheng.app` 与早期预览包 `com.zhiheng.mainpreview` 不能互相覆盖。启用辅助功能并选择小红书/抖音，打开一篇多图笔记，依次翻图；回到记录检查是否一条观看、展开原文是否保留看到的文字；退出再打开同篇，检查作品数与观看次数；打开另一篇同作者作品，确认没有误合并。分别检查今天、过去24小时和最近7天的各平台时长及报告。

真实平台资源节点与后台限制仍需真机验收。身份未知时，重点记录作者、标题、图片序号是否被读取，不用“没有重复记录”替代误合并检查。
