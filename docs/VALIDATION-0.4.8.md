# v0.4.8 统一观点分析链

验证日期：2026-10-10。版本 0.4.8，versionCode 15。

本轮推进报告中“输入、观点结构、历史比较与回顾共用分析结果”的部分：云端 `/monitor` 提取结果现在和浏览记录及完整原文快照关联，持久化后进入日报、时段观点、每日观点占比及 PDF/TXT 导出。它仍是有限采样的工程实现，历史论据比较仍使用本地规则。

## 已完成的变化

- Room v4→v5 新增结构结果表，不改写浏览记录的作品数、观看次数或停留时长；删除原记录级联删除结果。迁移保留作品、采样、音频及旧浏览记录。
- 采用模型原句、议题、对象、判断维度、立场、条件和论据；没有有效结果时保留规则候选。引文及论据必须是对应原文的连续子串，原文更正或增长后旧结果失效。
- 完整采样返回零观点时保留未知；部分采样的空结果不能覆盖未发送的文字或音频片段。缺少对象、维度、立场或议题时不生成确定的历史判断或重复提醒。
- 历史比较使用浏览时间排序，分析完成时间只选择结果版本。模型结果与规则候选分别比较，不制造互相支持的历史证据。同时间戳版本的选择在日报与图表中一致。
- 同一作品可保留多个观点，按完整上下文归组；每组对作品去重，总分母包含未知作品。比例重叠时使用独立比例条，各组之和可超过 100%。多个访问合并后，每个观点仍引用包含该原句的访问记录。
- 日报与导出显示模型采样结果覆盖、规则兜底、原文及方法限制。视觉提取文字标明来源，音频片段和视觉文字不增加作品接触数或观看时长。
- 设置恢复独立“云端分析”总开关。服务配置、采集范围、权限和删除代次参与迟到结果校验；过期请求不能恢复已清除缓存。

JVM 测试包括原有历史联合比较夹具、新增 20 个结构结果夹具，以及采样分配、失效快照、不同维度/条件/立场、多观点分母、同时间戳撤回、原文归属和未知告警回归。夹具集合内部有多项断言，不额外累加为独立 JUnit 测试数量。

3 项跳过均需要额外安装真实语音模型及公开 WAV/AAC 样例：本轮干净模拟器没有这些夹具。本轮没有重新测量真实 ASR 准确率，也没有调用付费模型或检索 API。测试只操作本次创建的独立模拟器，没有对原有模拟器或真机执行安装、卸载或数据清除。

lint 警告包括旧 target SDK、kapt 建议、arm64 专用包缺少 ChromeOS x86_64、既有未使用资源及悬浮窗可访问性/RTL 提示。

## 距离报告预想的剩余差距

| 下一步重点 | 当前边界 |
| --- | --- |
| 真实平台输入覆盖 | 当前是可见文字、短音频上下文和间隔画面；尚无完整跨页笔记、可靠视频边界和精确声画对齐。每次最多抽取 3 条候选，引用检查不证明整部作品已分析。 |
| 模型质量与阈值校准 | 尚无带标注的真实浏览评测集，未报告语义分类 F1、误提醒率、转写关键语义错误或干预效果。规范化标签不同仍可能漏掉语义相同的观点。 |
| 研究模型与时序图 | 双路编码、交叉编码、时序图/TGN、独立来源判断尚未实现；当前历史比较和时序汇总为本地规则。 |
| 持久异步任务 | 输入队列仍在内存中，有界容量 6；尚无跨进程任务恢复、持久重试及完整幂等任务索引。 |
| 隐私和长期运行 | 正文、结构观点及核查结果未额外加密，尚无 TEE/远程证明；目标手机耗电、温升、后台策略和长时连续输入仍需实测。 |

优先推进真实平台采样和标注评测，可用本轮已贯通的分析链验证误识别与漏识别，再决定模型和提醒策略的下一轮调整。
