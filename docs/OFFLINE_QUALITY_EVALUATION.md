# 结构观点与历史增量的离线标注评测

此入口用于把设计报告 2.5、2.6 中的“人工标注、独立测试、误报与覆盖”变成可执行工作流。当前固定集 `history-synthetic-v1` 包含 **112 个标注单元、26 个独立序列和 6 个专门标注的持续浏览窗口**，全部是手工编写的合成内容。其标注状态为 `single_editor_unadjudicated`，尚未经过双人独立标注和分歧裁定。

内容和预期标签由编码助手按场景含义逐项编写，没有使用真实用户记录，也尚未经过人类标注者复核。“金标”在这里指与算法输入分开冻结的预期标签，不代表已有人类共识或真实平台验证。

合成结果只用于诊断工程行为，不能当作真实平台准确率、用户风险率、内容真实性或心理影响的证据。模型抽取字段由文件提供，执行过程不调用云端模型。它测量的是 **给定这些结构字段后，实际 CognitiveAnalyzer 如何比较个人历史并生成提醒**，无法测量结构抽取召回率、视觉识别、正文/评论归属、模型校准或端到端质量。`local` 模式另保留少量本地兜底样本，并在完整分母中暴露提取缺失。

## 运行

需要项目现有的 JDK 21、Android SDK 和已缓存的 Android 构建依赖。先按项目正常构建流程准备依赖；本脚本不会联网补齐依赖。它会校验已准备的 sherpa AAR，缺失或校验失败时直接退出，防止自定义 Gradle 准备任务绕过 `--offline` 下载。

在仓库中执行：

```bash
bash scripts/evaluate-history-quality.sh
```

结果默认写入 `app/build/reports/history-quality/`：

- `summary.json`：可机器读取的每类 precision/recall/F1、两组混淆矩阵、覆盖、误提醒与文件 SHA-256。
- `report.md`：人工可读报告，含全部错误样本的预期、预测和标注理由。
- `predictions.tsv`：每个信息单元的完整预测；包含 UNKNOWN、未提取到观点和错误项。
- `window-predictions.tsv`：独立窗口的提醒预测。

其他标注集和结果目录通过参数指定；相对路径以调用脚本时的工作目录为准：

```bash
bash scripts/evaluate-history-quality.sh --dataset evaluation/datasets/synthetic-v1 --output /tmp/pojian-quality
```

底层 Gradle 入口也可单独执行：

```bash
./gradlew --offline :app:evaluateHistoryQuality -Pquality.dataset=/absolute/dataset -Pquality.output=/absolute/results
```

脚本不把错分样本当成构建失败；出现错误是评测结果，应保留金标并分析算法缺口。文件缺失、非法标签、重复 ID、输入与引文不符、无法唯一关联单元等结构错误则使运行失败。指标计算和转义处理另有 JVM 单元测试：

```bash
./gradlew --offline :app:testDebugUnitTest --tests 'com.emerge.app.evaluation.HistoryQualityEvaluatorTest'
```

## 文件与标注协议

每个数据集是一个目录，必须包含以下四个文件。输入与预期标签分开保存；评测器在运行分析器时不会向分析器传入预期标签。固定集包含故意不迎合当前规则的同义改写、数字与条目换序、多条历史联合覆盖、不同当事人使用相近句式等样本，不能为了提高分数而按预测修改标注。

`metadata.properties` 保存数据集 ID、性质、标注版本与状态。`kind` 只接受 `synthetic` 或 `consented_real`；后一值是数据管理声明，程序不能替代检查授权。真实集需在元数据补充采集授权范围、脱敏方式、源头分组、划分与复核状态，避免记录身份或凭据。

`inputs.tsv` 的字段为：

| 字段 | 含义 |
| --- | --- |
| sample_id / sequence_id | 单元唯一 ID / 用户历史序列 ID；序列之间不共享历史 |
| event_id / observed_seconds | 序列内浏览事件 ID / 固定基准时间后的观察秒数 |
| visible_text | 实际保留的完整观察文本 |
| quote | 该单元的连续原句；非 empty 模式必填 |
| topic / subject / dimension / stance | 输入给历史比较的结构字段；缺失值保留为空 |
| evidence / conditions / uncertain | 连续原文论据、适用条件、不确定标记 |
| mode | structured：提供结构结果；local：仅输入原文；empty：提供已完成的零观点结果 |

基准时刻固定为 `2026-10-05T00:00:00Z`，时区为 Asia/Shanghai，观察秒数为 0 到 518400。每次独立运行按该序列最后事件之后的时刻构造最近七天报告。输入事件与结构结果故意反序提交，检查浏览顺序不依赖文件排列或分析完成顺序。每个事件使用明确的 15 秒合成停留时长，此时长是实验控制量，不能冒充实测阅读投入。

同一事件最多三个结构单元；它们必须有相同的事件文本、时刻和模式，并能通过引文/论据的逐字校验。`empty` 和 `local` 每事件只占一行。真实结构抽取评测需要另建预测文件，先对人工金标做单元匹配，再把抽取遗漏、错误关系和未知纳入分母；不能把本入口的 supplied fields 结果改名为端到端模型结果。

结构模式按事件 ID、原句、维度和立场匹配目标单元。本地规则会保留含行内依据的整句，因此本地模式允许整句包含人工标注的连续主张片段；匹配结果必须唯一，不使用增量金标选择候选。这样不会把输出范围较长误算成漏提取，也不会把不同事件或不相干原句混入对照。

`labels.tsv` 保存 `sample_id`、`expected_increment`、`challenge`、`rationale`。当前标签沿用产品输出，但预期依据由内容含义和历史证据独立制定：

| 标签 | 独立标注含义 |
| --- | --- |
| FIRST | 明确、可归属的此观点首次进入可观察历史；不是知识新增或真实可靠的结论 |
| NEW | 相对已观察的可比历史确有新事实、论据、解释或行动建议；真实性另行判断 |
| REPEATED | 当前判断与依据的含义均已由可比历史覆盖，包括改写或多条旧材料联合覆盖 |
| CONDITIONS | 对象与判断相关，但时间、人群、地区或其他适用范围实际不同；同义条件不属于变化 |
| UNKNOWN | 归属、维度或可比依据不足，无法判断新增与复用；缺失不作为不存在的证据 |
| NO_CLAIM | 人工确认当前观察片段没有目标观点；当模型漏掉已标注观点时，此值也作为预测错误保留 |

相反立场首次出现标 FIRST，并归入 `reversal` 难例；当前输出还没有专门的“支持/反驳关系”标签，因此这个试验不能证明关系抽取已完成。原句、限定和来源中存在实质歧义时应标 UNKNOWN 并记录理由，不借助未观察的完整视频补齐。

`windows.tsv` 保存 `sequence_id`、`expected_alert`、`challenge`、`rationale`。仅为专门的多事件窗口填写预期，不把所有短配对序列纳入误提醒分母以稀释误报：

- ALERT：观察范围内持续同观点、同依据且缺少实质补充，可以提示回查来源。
- NO_ALERT：观察与可比关系充分，但持续有实质补充或其他证据不支持低增量重复。
- INSUFFICIENT：观察仅限短时，或大量归属/依据未知，不能据此确认长期状态。

这是接触结构标注，不是用户信念、心理或平台意图标注。固定集中的“多个相似失败故事”明示来自不同当事人，各自增加个体事实；相近句式不等于同一事实。是否扩展对行业的理解另行评价，不能把此合成窗口推广为所有案例内容的风险判断。

TSV 第一行必须严格匹配列名。单元格使用 `\\n`、`\\r`、`\\t`、`\\\\` 表示换行、回车、制表符与反斜杠；未知转义报错。空值保留空列，不能删除列。每个输入单元必须恰有一个增量金标，金标不得引用不存在的 ID。

## 指标与分母

每类 precision 的分母是预测为该类的单元数，recall 的分母是人工标为该类的单元数，F1 为 `2TP / (金标数 + 预测数)`。分母为零时 JSON 保存 null、Markdown 显示破折号；类别有金标但没有预测时 F1 为 0。macro-F1 只对有金标样本的类别取平均。

完整混淆矩阵和整体准确率涵盖全部标注单元，包括 UNKNOWN 和 NO_CLAIM。可判断增量覆盖率为预测 FIRST、NEW、REPEATED、CONDITIONS 的数量除以全部标注单元；仅可判断项准确率另列，不能替代整体准确率。结构事件覆盖是已提供且实际接受的结构结果数除以全部事件数；它不等于观点、图像或时间的分析完整率。

窗口误提醒率为 `金标NO_ALERT且预测ALERT / 所有金标NO_ALERT窗口`；金标证据不足仍提醒另计，正类未提醒（包括输出证据不足）计漏提醒。窗口可判断覆盖率为预测 ALERT 或 NO_ALERT 的窗口数除以全部独立标注窗口数。

`summary.json` 同时保存数据文件和分析源码的 SHA-256。结果不写运行时间，因此同一数据与源码可逐字复跑比较。变更分析逻辑、标注协议或数据时应保留旧结果，建立新的基线；不能把修改后的固定集合分数当作独立测试集的进步。

## 0.4.9 固定合成基线

本次已保存 [完整报告](../evaluation/baselines/synthetic-v1-0.4.9/report.md)、[机器指标与文件校验](../evaluation/baselines/synthetic-v1-0.4.9/summary.json)、[逐单元预测](../evaluation/baselines/synthetic-v1-0.4.9/predictions.tsv) 和 [逐窗口预测](../evaluation/baselines/synthetic-v1-0.4.9/window-predictions.tsv)。四个文件经过独立重复运行后逐字相同；评测器的四项 JVM 测试通过。

信息增量判对 94/112（83.93%），macro-F1 为 0.8016；窗口判对 5/6（83.33%），macro-F1 为 0.8222。增量可判断覆盖为 93/112（83.04%），负类窗口误提醒为 1/3，证据不足窗口未触发提醒。两个本地就业样本采用正确的连续主张匹配：规则输出的整句包含行内依据，不能因输出范围较长被误算成漏提取。运行器已修复该匹配偏差，这份基线使用修正后的结果，输入和预期标签保持不变。

当前错误集中于同义数字和立场、同义条件、论据换序、旧材料联合覆盖，以及不同当事人使用相似句式。其中不同求职者的独立经历有 11 次新增被判为重复，并造成唯一一次窗口误提醒；水质主题的本地词表缺失造成一次漏提取。这些结果保留在基线中，后续应优先改进事实与来源身份、同义规范化及跨历史单元覆盖，再用独立复核数据验证。窗口仅六个、CONDITIONS 金标仅一个，比例不能用于估计真实场景的风险水平。

## 转为真实标注工作流

1. 在明确授权范围内采样真实观察前缀，脱敏并保留正文/评论、时间、源头与缺失状态；原文、视频、评论线程和同源转载按组隔离，防止训练/测试泄漏。
2. 先写标注准则和边界例子，再让两名标注者独立判断观点、论据、条件、历史覆盖及窗口状态。各自原始标签保留，不先查看模型输出。
3. 计算标注一致性、复核分歧并记录裁定理由；无法裁定的样本保留 UNKNOWN，而非从测试集移除。当前合成集单编辑者结果没有这种一致性证据。
4. 划分训练、校准与测试。阈值或拒识边界仅在校准集调整；测试集冻结，按主题、材料源头、观察时长及缺失比例分别报告结果。
5. 运行实际抽取模型，保存模型/提示/输入版本与完整预测，先评测抽取及证据关联，再评测历史链；并列提供“人工结构输入”和“模型结构输入”结果，定位错误来自哪里。
6. 在此前提下扩展多维增量、图统计和时序模型对照。当前入口没有概率输出，不报告 Brier/ECE，也不能代替报告 2.8 的情绪角色、诱因和个人反馈评价。
