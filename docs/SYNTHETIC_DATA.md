# AI 合成数据与开发回归

当前 App 已移除内置模拟数据及演示、实验数据库入口。本文件保留演示 v1 的历史记录与开发回归方法；588 个作品的 JSON 已移到 `app/src/test/resources/synthetic/demo-v1.json`，只参与 JVM 测试，不进入 APK。生成器和测试继续保留。论文用途应参见独立的 [受控合成数据集 v2](RESEARCH_SYNTHETIC_DATA.md)及[开发用实验数据库](PROJECT_RESEARCH_DATABASE.md)，不要把本演示集作为论文实验集。

本次数据是 AI 编写模板后由确定性脚本展开的虚构材料，供 App 展示、结构检查和统计回归使用。不是实际平台采集、真人参与者、人工金标或模型性能结果。模拟日期固定为北京时间 2026-09-29 至 2026-10-12，回顾时点为 23:00。

## 旧版 App 演示实现（历史记录，入口已移除）

旧版入口为 **设置 → AI 合成演示**。可切换前后两个七天，以及今天、过去 24 小时、最近 7 天；点击趋势柱查看作品及多次观看详情。顶部始终显示合成来源和模拟时点，结构化字段显示为“合成标注”。没有真实图片，因此缩略图保持占位。

入口使用 `pojian-synthetic-demo-v1.db`，与真实记录的 `zhiheng.db` 分开。进入时在事务中重置这一个演示库；中断后回滚，重进可重试。素材通过 Room 读回，再交给现有统计和分析器。演示库没有接入生产 Repository、后台分析队列、截图服务或云端调用，不修改采集和上传授权。主记录清除功能的语义不变。

统计计算在后台线程进行，切换范围可取消旧计算；关闭后释放数据库连接；信息茧房动画离开可见区域后暂停。尚未进行真机加载耗时、帧率和界面截图验收。

## 论文规模参考与划分

用户扩展后的“七种组合各 2,000 个”合计 14,000，与 6,000 总量矛盾。仓库 LaTeX 原文为小红书图文、小红书短视频、抖音短视频各 2,000 个。当前按原文生成可选的 **6,000 条模板作品、18,000 个观察版本**；七种组合均已进入 App 演示。

- 六领域各 1,000 条；配额划分 4,200 / 900 / 900，版本为 12,600 / 2,700 / 2,700。
- 测试配额六领域各 150 条，三种组合各 300 条。
- 在扩展作品前分配作者组与证据模板家族；家族归为近重复组，跨划分不共享。版本继承作品划分。检测作者、作品 ID、模板家族、近重复组和完全相同正文是否跨划分。
- **只有 18 个编写的证据模板家族**，再组合条件、情绪和情境参数形成 6,000 条记录。它们不等价于 6,000 篇独立采集的自然作品；即使通过组隔离检查，也不能用作已验证的语言泛化基准或报告论文模型准确率。共享的观点标签仍可能让任务过于简单。
- 三个版本依次为标题、可见论证和保留正文，使用递增 `observedAt`、`availableAt`。后续情绪上下文不会出现在早期版本；证据索引回指当时可见文字。
- 情绪跨度采用 Unicode 码点的左闭右开索引。当前文本不含辅助平面字符；后续若加入表情，Android UTF-16 索引需要转换。
- 没有构造或宣称已完成 12,000 组历史增量金标、8,000 条独立情绪金标、200 位志愿者、2,800 个真人用户日、240 条人工轨迹或 120 个已执行安全场景。没有伪造媒体授权或撤回记录，也没有进行训练。

## 复现和交付文件

在仓库根目录运行 Python 3.10+：

```powershell
python scripts/generate_synthetic_data.py --research
python -m unittest discover -s scripts/tests -p test_synthetic_data.py -v
```

默认输出 `app/build/synthetic-data/`：

| 文件 | 用途 |
| --- | --- |
| `demo.json` | App 演示的全部作品、事件、采样、标注和未观察区间 |
| `pojian-synthetic-demo.db` | 独立 SQLite 文件，兼容导出的 Room 8 schema，可直接检查表内容 |
| `works.jsonl` | 6,000 条模板作品，含分组、划分、论证和情绪标注 |
| `observations.jsonl` | 18,000 个部分观察版本 |
| `manifest.json` | 来源、数量、模拟时间、限制和 demo JSON 的 SHA-256 |

脚本不读取设备数据；拒绝向 `zhiheng.db` 等非专用文件名写入，也拒绝覆盖无法识别的已有数据库。不要把交付 SQLite 覆盖到真实记录文件上。需要明确更新版本化的 JVM 测试夹具时使用 `--write-test-fixture`；该选项不会写入 App 资源目录。
