# 作品设计对齐：历史联合覆盖与证据关联

日期：2026-10-08。对照用户提供的《破茧：个人认知体检工具——作品报告（第一、二章合订版）》，基于仓库提交 `b8c96ea19b9d4757af890928f156c28dc80e5279` 完成。本次是现有本地规则分析链路的工程修正，不是报告中全部研究模型的实现或效果验证。

## 修改与设计依据

**个人可比历史（2.5.1）。** 比较记录必须满足 `历史.timestamp < 当前.timestamp`，同一事件或相同时间戳的其他事件不能作为当前历史。按议题、对象和观点方向建立本次分析内的索引；先筛选可比条件，再限制候选数量，避免最近的无关记录挤掉有效旧材料。仍使用现有规则识别议题、对象和条件，尚未建立完整的片段级历史版本快照。

**历史联合覆盖（2.5.4）。** 从仅比较最近一条记录改为逐片段对照同范围候选历史的证据并集。旧材料 A 覆盖事实一、旧材料 B 覆盖事实二时，当前重新组合这两项事实不再被判为新增。新旧混合时仅标记未匹配的片段，最近一条材料没有证据也不会遮蔽更早的有效匹配。

**未知状态与可核查依赖（2.5.5、2.10.3）。** `EvidenceFragment.historyMatches` 保存直接匹配的历史记录 ID 与原文，每个片段最多保留三处匹配；`ClaimObservation.comparedHistoryEventIds` 保存本次实际比较的历史范围。候选最多 120 个论证单元，达到截断条件时设置 `historyComparisonTruncated`。全部片段已经找到匹配仍可输出重复；存在未匹配片段则保留为未知，而非宣称新增。对象不明、引用归属不明和证据缺失也保留未知。

**避免字面近似掩盖含义变化（2.5.2）。** 数字比较保留正负号、大小关系和单位，片段匹配额外检查否定、增减和数量限定词。此处只是保守规则保护，不是经过训练或校准的语义关系模型；仍可能误判改写、隐含条件和引用范围。

**持续同观点低增量（2.6、2.10.4）。** 最大相似观点组的重复分子只取该组的重复记录，不能用其他观点组的重复数量触发最大组的收窄提示。原有启发式观察门槛保持不变，说明文字补充候选截断情况与新颖性不等于真实性、来源独立性的边界。这不是时序图模型或校准风险概率。

**删除、更正与音频证据（2.9.4、2.10.3）。** 历史索引只在单次分析中存在，重新分析删除或更正后的输入会重新生成依赖，不保留旧索引。音频回顾优先展示真正变化的片段；历史引用必须确实包含对应片段，不再默认指向最近的相似记录。未匹配的新片段不附加虚构历史引用。现有音频结果格式仍只展示一处直接匹配，摘要说明联合比较与单处展示的区别；尚未增加完整多历史证据浏览界面。

## 兼容性与范围

只修改 `CognitiveAnalyzer.kt` 和 `AudioInsights.kt` 两个生产文件。新增字段位于报告数据类末尾并提供默认值；不修改 Room 表、数据库版本、应用 ID、权限、云端服务协议、采集授权或隐私默认值。分析方法标记更新为本地规则 v0.4，应用发布版本仍为 0.4.1；本次不发布 APK。

以下仍需独立实现和验证：双路训练编码器、交叉编码器、多模态模型、时序论证图、片段版本快照、浏览器端、完整派生数据持久化依赖索引、真实 TEE 与远程证明。普通文字网关不因此成为机密计算环境。规则输出不能用作用户心理状态、观点认同或事实真实性判定。
