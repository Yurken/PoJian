# 复赛工程改造与验收

本轮按 `server/` 原地升级，保留现有 HTTP 路由、管理员认证和既有配置；不新建第二套后端目录。现有文档与参考 PDF 的章节编号不同，报告按实际标题修改。

## 工程落地

| 范围 | 实现与验收口径 |
| --- | --- |
| 结构化推理 | 商业模型一次生成观点、事实、历史覆盖、外推证据和盲区；JSON Schema 与本地类型校验共同约束。事实与结论必须是原文连续子串，不去标点拼接“原文”。计数由程序重新计算。 |
| 认证加密 | Ed25519 公钥固定校验、X25519、HKDF-SHA256、双向 AES-256-GCM。签名绑定随机数、会话、双方公钥、度量与时间。客户端不内置共享签名秘密。 |
| 状态连续性 | 每客户端持久化版本与哈希，严格比较、事务提交、认证响应；模型失败不提交状态，重试不重复推进。手机检查点受 Keystore 加密保护。 |
| 管理演练 | 沿用管理员认证；调试开关默认关闭；仅展示密文摘要、度量与安全状态，不展示用户正文。演练开关与实际漏洞利用分开标识。 |
| Android | 保留旧队列加密格式；新增 V2 结果持久化、隐私正则掩码、最近 15 条历史事实、全局安全阻断、原文对照与盲区查询。 |
| 统计 | Room 9→10 平滑迁移；事件贡献和事实身份索引支持增改删、重分析及跨日去重，日报/月报摘要读取物化表。完整报告的原文证据部分仍需明细数据。 |

## 统计与界面边界

- “独立事实”与“独立来源”是两种统计，不互相替换标签。已完成的空分析显示真实的 0；尚未分析的数据保留缺失状态。
- 新增事实相对于本次携带的有限历史候选计算；最多 15 条候选不等于完整历史穷尽核验。同源说明只使用模型在有效历史引用下返回的内容，不硬编码“14 条”。
- 事实性表述与情绪化表达的比例来自校验过的 `expression_spans`。同一作品去重，以已标注的不同片段数为分母；缺少标注时不把非阳性分析当成事实性表述。
- 无直链时提供平台内“搜索出处”，不能声称搜索链接精确定位原视频。未安装对应应用时回到本地原文。
- 信息盲区仅来自已保留分析，查询由用户点击触发；编辑后的检索词发送前再次执行本地正则掩码。

## 安全能力边界

这是应用层签名与加密协议，不是 Intel TDX / GPU 硬件远程证明。获授权的服务进程会解密，商业模型服务会收到脱敏文本。不能宣称管理员永远无法读取运行内存、云端全程零明文、密钥在 Python/Java 内存中已可靠清零，或获得了硬件隔离证明。

代码度量及签名的信任依赖发布公钥、批准度量和服务端私钥的安全保管；攻击者同时取得私钥和运行权限时，该机制不提供硬件级保护。状态回滚检测依赖手机保留最新检查点；客户端与服务端同时回滚不能仅靠哈希链检测。正则掩码覆盖手机号、身份证号、邮箱及已识别通知前缀，并不保证去除所有个人身份特征。

新协议必须配置服务端密钥及客户端公钥、批准度量。没有配置时沿用原服务模式；启用新协议后验签、认证或状态校验失败不得自动降级上传。演练使用测试数据，不调用清库、恢复生产快照或修改生产程序来模拟攻击。

Android 构建从忽略的 `local.properties` 或 Gradle `-P` 参数读取 `pojian.secureEndpoint`（HTTPS 根地址）、`pojian.attestationPublicKey`（Base64 编码 Ed25519 原始公钥）、`pojian.codeMeasurement`（批准构建的 SHA-256 十六进制）。三个值必须与同一服务端发布版本匹配；App 设置的服务地址必须与该可信端点一致。验签公钥和度量是公开发布配置，服务私钥及模型密钥只放服务器环境。协议初始化及服务端配置见 `server/README.md`。

默认供应商使用 JSON 对象模式并进行严格本地 Schema 校验；只有确认支持时才配置 `LLM_RESPONSE_FORMAT=json_schema`。未配置模型不会伪造有效分析结果，既有离线规则与旧路由继续独立工作。

## 验证与报告

1. 运行现有服务端测试及新增安全、结构化解析测试；覆盖篡改、错误历史引用、重放、回滚、并发、失败重试与审计脱敏。
2. 运行 Android 全量 JVM 测试并编译设备测试，覆盖旧记录兼容、V2 字段、隐私、链接、密码学和统计。
3. 用生产迁移 SQL 在 SQLite 验证旧数据保留、跨日去重、重分析和级联删除；性能记录区分写入、首次回填、预热摘要查询和完整 PDF。
4. 商业 API F1、误报率、P50/P95、Android 设备耗时及新界面截图必须来自真实实验。现有初赛图表不作为新增 API 模式的结果，不承诺亚秒或零误报。
