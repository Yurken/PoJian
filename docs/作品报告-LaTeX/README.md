# 破茧作品报告 LaTeX 工程

按用户提供的中国研究生网络安全创新大赛 `cgscic` 模板，整理作品报告第一至第五章。包含摘要、封面、填写说明、三级目录、37 条参考文献、12 张配图、18 张表和 12 个公式。

## 文件与编译

- `main.tex`：报告入口；作品名称和提交日期可在这里修改。当前日期为 2026 年 10 月 11 日。
- `setting/cgscic.cls`：由用户粘贴的模板整理的文档类。
- `chapters/chapter-1.tex` 至 `chapter-5.tex`：分章正文。
- `references.bib`：统一书目，键为 `ref1` 至 `ref37`。
- `figures/`：正文引用的 12 张 PNG 配图。

需要安装含 `ctex`、`gbt7714` 和 Fandol 字体的 TeX Live / MacTeX。使用 XeLaTeX 和 BibTeX，由 latexmk 自动完成多轮编译。无需系统安装宋体字体，也无需联网或启用 shell escape。

在本目录执行：

```bash
bash build.sh
```

编译后的报告为 `build/pojian-report.pdf`，PDF 和编译中间文件均不提交到 Git。使用独立作业名 `pojian-report`，避免与编辑器生成的 `main.*` 文件相互干扰。也可直接运行：

```bash
latexmk -xelatex -jobname=pojian-report main.tex
```

## 模板与材料

模板来自用户在对话中提供的 `cgscic` 文档类及示例入口，原始链接为[模板文章](https://mp.weixin.qq.com/s/KNSGo92cgprgGlF7LCt2rA)。本文采用 A4，左/右页边距 2.86/2.59 cm，上/下 2.5 cm，宋体小四、1.5 倍行距，保留模板的填写说明页与“第 x 页 共 y 页”页脚。Fandol 中文字体和 TeX Gyre 西文字体随 TeX 发行版加载，便于跨平台编译；三级目录编号栏加宽以容纳 `2.10.4` 等编号。

第一、二章按用户于 2026 年 10 月 19 日提供的《一二章.md》更新，保留原稿正文、层级、公式、表格和流程图。四张流程图使用附件目录中的 PNG；隐私保护图的 Markdown 路径指向未提供的 Windows 文件，因此从同目录《一二章.pdf》第 25 页提取原始嵌入图像。第三章来自《破茧第三章作品测试与分析》，第四章来自《破茧作品报告第四章创新性说明》，第五章为已有的作品总结。

## 合并调整

第一、二章使用 LaTeX 自动章节编号；第二章五张图、四张表和十二个公式分别编号为 `2-1` 至 `2-5`、`2-1` 至 `2-4` 和 `2-1` 至 `2-12`。原稿中未编号及使用 `2-X` 占位的表题改为自动编号，正文表引用同步更新，图注不保留文件名中的“模板风格”等后缀。第三章“表 3-2a”改为“表 3-3”，后续表顺延；原未编号的突发负载表补为“表 3-11”，原安全表、验收表分别成为“表 3-12”“表 3-13”。

第三章的四条设备资料保留为书目 `ref30` 至 `ref33`，原前两章的 `ref1` 至 `ref29` 保持次序；第四章沿用这些引用。更新稿中的引用 `[30]` 至 `[33]` 分别映射到新增条目 `ref34` 至 `ref37`，避免与设备资料混用；新增四条文献的书目信息按期刊及 NIST 官方资料补齐。书目保留原稿的 DOI、URL、日期与访问日，未提供且未核实的日期不补造。

本轮仅替换第一、二章，并删除第四章两处指向已移除表格的引用。摘要及第三至第五章仍沿用既有版本，其中的方法描述和第四章对旧版第二章公式、节号的文字引用尚待后续同步；本次编译通过不代表这些章节已经与新方法逐项对齐。

第四章按用户要求缩短了各级标题，并做了六处衔接调整：修正四项研究任务对应的章节；说明阅读投入属于估计；区分真实感受标签与个体校准估计；将两处未经查新支持的优先性声明改为设计特点；将总览中的消融描述调整为第三章实际报告的项目。研究计划、交互示例、实验值及其范围限定继续按原稿保留，数据未在本次排版工作中重新进行模型实验复现。

## 编辑正文

直接编辑 `chapters/` 中对应的 `.tex` 文件，再运行 `bash build.sh`。正文直接维护在 LaTeX 文件中，编辑和编译不依赖 Python 或 Pandoc。
