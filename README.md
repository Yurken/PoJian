# 破茧 Emerge

> 看见信息边界，拓宽判断依据。

每天刷过很多内容，哪些带来了新的信息，哪些只是在重复熟悉的判断？

破茧是一款 Android 信息回顾工具。它记录你在选定应用中接触到的文字，整理主题、观点线索与相关依据，让你带着原文回看自己的信息环境，决定接下来想查证什么、了解什么。

**Android 10+ · 测试版 v0.3.1 · 本地离线运行**

## 可以用它做什么

- **回看一天。** 按 24 个小时查看接触记录和估计停留时长，也可以回顾最近 7 天。
- **核查反复出现的判断。** 查看观点线索、相关依据和历史关联，点开原文自己判断。
- **按自己的目的理解浏览。** 结合学习、查资料或休闲等目的回顾接触内容，娱乐也有它的价值。
- **管理与留存。** 按日期回看记录、按应用筛选和搜索原文，删除单条、某个应用或全部内容，将观察报告导出为 PDF 或文本。

## 开始使用

1. 在「控制」选择允许采集的应用。默认不采集任何应用。
2. 前往系统辅助功能设置，启用「破茧浏览采集」，返回破茧后打开采集开关。Android 13 及以上的侧载安装可能需要先在应用信息中允许受限设置。
3. 在选中的应用里正常浏览文字内容，再到「记录」查看采集到的原文。
4. 在「概览」选择今天或最近 7 天，填写浏览目的，生成观察。点击小时条或观点线索，可以进一步核查原文。
5. 需要留存时导出报告；后续有新记录，可以刷新分析后重新导出。

目前可自行构建安装：用 Android Studio 打开本仓库，连接手机后运行；或在配置好 Android 开发环境后执行：

```sh
./gradlew assembleDebug
```

已安装旧版「知衡」的用户，请使用同签名安装包覆盖安装，以保留已有数据；不要先卸载。升级后需重新选择采集范围并主动开启。

## 数据由你控制

采集范围由你选择，随时可以暂停或删除。所有记录与分析留在本机，无需账号、API 密钥或服务器，也不会上传浏览内容。最多保留最新 5000 条记录。

采集会跳过密码和可编辑输入框，但页面正文仍可能包含私人信息。本地数据库暂未额外加密。导出到应用之外的报告需要自行保管和删除。

## 现在做到哪一步

当前版本使用离线文字规则，尚不能理解图片、视频画面或音频。部分应用无法提供可读取的文字，因此记录不一定完整。

估计停留时长不等于实际阅读，文字线索也不能判断你是否认同某个观点。分析供你回看与查证，准确性和使用效果仍需验证。
