# 破茧 Emerge

> 察觉观点重复，查证眼前信息。

当前个人分支包含 0.4.2 作品／观看／采样分层、今天／过去24小时／最近7天统计、APP折叠足迹及报告统计。作品身份仍有启发式限制，详见[作品与观看统计](docs/WORK_VISITS.md)。下文的实时核查和视觉能力需配置网关，不会因升级自动开启。

破茧是一款面向图文笔记、短视频和文章浏览的 Android 信息环境监测与事实核查原型。它关注两件事：**接触的观点与论据是否持续单一，以及眼前的具体声明是否有可追溯的外部依据。** 录音、转写和画面采样只是材料入口，不是产品主角。

应用内分为「概览／发现／设置」：概览保留今天、七日和小时统计；发现分别展示观点重复线索与事实核查证据；设置管理范围、悬浮球、分析开关和费用上限。录音与模型下载下沉到设置中的「采集工具」。

## 浏览时怎样工作

在用户选定的应用中，悬浮球提供「核查当前内容」「查看证据与统计」「暂停全部监测」。平时贴边显示、可拖动，默认静音、不振动、不抢焦点。只有持续重复线索或具有外部引文的证据矛盾才可能主动展开；设置可调整冷却时间、每日提醒次数、提示时长、夜间免打扰和专题研究模式。

图文不需要先录音。可见文字进入本地观察和可选实时分析；另行开启关键画面分析后，当前可见图片可发送给视觉模型。播放音频仍在本机转写，稳定片段写入后可自动进入相同核查入口，不必等到整次录音结束。核查迟于切屏时保留到发现页，不应作为下一屏的结论弹出。

「女性独立」「某品牌是国产之光」等价值表达本身不是虚假信息标签。系统区分议题、对象、评价维度、观点、论据和条件；观察到重复不等于已经证明用户陷入信息茧房，看过也不等于认同。

## 开始使用

1. 在设置选择允许监测的应用，在系统辅助功能中启用「破茧浏览采集」，返回打开采集开关。默认不选择任何应用。侧载安装可能需要先允许系统的受限设置。
2. 按需开启悬浮球和实时事实核查。配置新版[分析与取证网关](server/README.md)，填写网关地址、访问令牌及每日共享请求上限。没有检索配置时会显示「未完成核查」，不会以模型记忆冒充外部证据。
3. 图文或无声视频：另行开启「关键画面分析」，并在网关配置视觉模型。播放口播：进入「设置 → 采集工具」，下载约 31 MB 的中文模型，选择播放应用并完成系统授权。音频导入保留为备用入口。

**兼容范围：** 文字与播放音频面向 Android 10+；本次关键画面采样使用辅助功能截图 API，需要 Android 11+，Android 14+ 优先截图目标窗口。悬浮球使用辅助功能覆盖层，与辅助功能授权绑定，不另建隐蔽采集服务。播放内录受来源应用策略限制，受保护的画面可能无法采集；不会绕过这些限制。

## 核查与费用

新版 `/monitor` 网关先抽取最多三条声明，再对其中最多一条事实声明检索网页正文并对齐证据，返回来源、连续引文和结论。观点、未核查、证据不足、资料支持、证据矛盾和证据分歧分别保留。取证失败、上下文不明或引文不匹配不会输出确定的真假提醒。

当前采用有界队列、完全相同输入的短期缓存、重复画面去重、画面采样间隔、每日画面额度和共享请求额度控制成本。**一次网关请求可能包含多次模型与检索调用，不等于一次模型计费。** 未显示部分、未采样帧和超出预算的声明没有被核查；没有提醒不代表内容真实。

## 构建与测试

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
python -m unittest discover -s server/tests -v
bash scripts/check-monitor-core.sh
```

首次 Android 构建会下载并校验固定版本的 sherpa-onnx 推理库。应用 ID 与数据库文件名保持不变；0.4.2 将 Room v3 迁移至 v4，保留原有记录。使用相同安装身份、相同签名的安装包覆盖安装，不要先卸载。独立预览包应更新之前的预览版，不用于覆盖已放弃开发路线的旧实验包。构建特定设备包可使用 `-PemergeAbi=arm64-v8a`。

## 数据与边界

实时核查、画面上传和云端网关默认关闭。启用相应选项后才自动发送所选应用的文字或采样画面；原声音频不上传，截图只作短时输入，不保存为原始图像文件。系统录音与授权提示保留。服务端保存模型与检索密钥，手机用系统密钥库保护访问令牌；正文、视觉模型提取文字和核查结果未额外加密，可在本机清除。

这是工程原型，不是已经验证准确率的信息茧房诊断器或视频鉴伪系统。当前仍缺少完整的跨页笔记归并、可靠的推荐流/搜索入口识别、精确声画对齐、连续视频时序推理和经过标注校准的提醒阈值。视觉文字由模型提取，可能有错；不能用引文字符串检查替代真实性验证。
