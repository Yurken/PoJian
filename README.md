# 破茧 Emerge

> 看清信息环境，拓宽判断依据。

每天刷过很多内容，哪些带来了新的信息，哪些只是在重复熟悉的判断？

破茧是一款 Android 信息回顾工具。它把选定应用中的可见文字和口播转写整理成可查回原句的记录，帮助你回看主题、观点与依据，决定接下来想查证什么。

**Android 10+ · 测试版 v0.4.1 · 功能极简 2.0 · 本地语音转写 · 可选云端文字分析**

## 可以用它做什么

- **留下听到的内容。** 导入音频或视频的音轨，或授权记录某个应用的播放声音；本地中文小模型分段转写，保留时间位置。
- **回到原句核查。** 查看自动转写、修订文字、生成观点与依据回顾，并和之前保存的音频文字比较。修订保留原始转写；改写或删除历史材料会使相关旧回顾失效。
- **回看一天。** 继续支持可见文字采集、今天 / 最近 7 天、24 小时接触记录和估计停留。音频长度不计作观看时长。
- **管理与留存。** 按日期、应用和关键词查找记录，删除单条、音频会话、某个应用或全部内容；将整体观察导出为 PDF 或文本。

## 开始使用

**听声音：** 在「录制」下载一次中文语音模型（约 31 MB），然后点击「导入音频」。文件在本机处理，单次最多处理前 5 分钟；支持系统能够解码的音频，也可选择视频并只读取音轨。

**记录播放声音：** 先在「设置」选择允许记录的应用，再在「录制」点击「记录播放声音」，选择一个应用并完成系统授权。通知、「录制」和「分析」中的录制卡均可暂停、继续或停止。部分应用禁止内录，遇到静音可改为导入自己持有的文件。程序不采集麦克风、不保存屏幕画面。

**采集可见文字：** 在系统辅助功能中启用「破茧浏览采集」，返回 App 打开文字采集开关。在选定应用中浏览后，到「足迹」回看原文。侧载安装在部分系统上需要先允许受限设置。

**看图回顾：** 「分析」用 24 小时热图表示保存记录的数量，点击时段可查原文。生成回顾后，用蓝色、橙色和灰色分别显示新增、重复及其余观察的数量；首次、条件差异和未知均保留在分母中。

**生成音频回顾：** 打开音频记录详情，核查或修订转写后点击生成回顾。默认使用本地文字规则；需要更强的语义分析时，可按[文字服务部署说明](server/README.md)配置服务，在设置中主动启用并设置每日调用上限。

用 Android Studio 打开仓库并运行，或在配置好 Android 开发环境后执行：

```sh
./gradlew assembleDebug
```

首次构建会下载并校验固定版本的 sherpa-onnx Android 推理库；语音模型由用户在 App 中另行下载。已安装旧版的用户请使用同签名安装包覆盖安装，以保留本地记录；不要先卸载。

仅面向常见的 64 位 ARM 手机时，可用 `./gradlew assembleDebug -PemergeAbi=arm64-v8a` 缩小安装包；默认构建包含四种 CPU 架构。

## 数据由你控制

默认不采集任何应用。语音转写在手机上完成，只保存文字与时间，不保留原声音频。最多保留 5000 条文字记录；可随时停止或删除。

云端文字分析默认关闭。启用后，只有手动生成音频回顾时才会发送当前转写和少量相关历史文字；音频不会上传。模型服务 API 密钥保存在服务端，手机仅保存经过系统密钥库加密的服务访问令牌。每日限额按请求次数计数，失败请求也计入。

本地数据库未额外加密，正文可能包含私人信息。导出的外部文件需自行保管和删除。

## 当前边界

转写可能听错数字、否定和人名，需要核查。观点与历史增量仍是辅助线索；本地规则覆盖有限，引用检查也不能证明语义判断正确。当前不理解视频画面，不自动下载分享链接，不提供原声回放。

本地识别及工程回归已有验证；目标短视频应用的内录兼容、真机耗电、转写准确率与比赛对照实验还需实测。
